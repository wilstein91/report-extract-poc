## 모델·라이브러리 라이선스

확인 방법은 저장소 첫 화면의 표시가 아니라 **설치된 배포본의 메타데이터**다.

```bash
uv run python -c "from importlib.metadata import metadata; print(metadata('pymupdf')['License'])"
ollama show gemma4:e4b --license
```

`uv pip show` 는 License 필드를 출력하지 않는다. 그것만 보고 확인했다고 하면 안 된다.

### ① PyMuPDF 의 배포 조건

PyMuPDF 는 AGPL-3.0 이다. 닫힌 제품에 넣어 **배포**하면 소스 공개 의무가 걸리고,
만든 쪽(Artifex)이 그 의무를 없앤 상용 라이선스를 따로 판매한다.
개인이 자기 노트북에서 돌려 쓰는 것은 배포가 아니므로 이 PoC 범위에서는 문제가 없다.
교안이 자세 추정 도구의 AGPL 사례로 든 것과 같은 구조다.

### ③ 을 제외했다가 되돌린 경위

처음에는 아래 재배포 고지를 근거로 외부 API 후보를 제외했다.
그러나 제외 조건을 정하는 것은 업무를 아는 사람이지 도구가 아니다.
사용자가 실제 도입 시 Claude 를 쓸 계획임을 밝혔으므로 후보로 되돌렸고,
API 키가 없어 이번에는 측정하지 못했다. **추측으로 점수를 채우지 않는다.**

확실한 것: 원본 PDF 를 저장소에 커밋하거나 남에게 넘기는 것은 재배포다. → 하지 않았다.
불확실한 것: 열람 권한을 가진 본인이 읽으려고 도구에 넣는 것이 여기 해당하는지.
→ 법률 판단이 필요한 영역이며 이 문서는 그 판단을 하지 않는다. 도입 전에 확인할 항목으로 남긴다.
